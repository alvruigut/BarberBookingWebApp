# BarberBookingWebApp 💈

Aplicación web para la **gestión de citas de peluquerías y barberías**.

Permite disponer de una plataforma para organizar y gestionar las reservas de los clientes desde una aplicación web.

## 🛠️ Tecnologías

El proyecto está desarrollado utilizando:

### Backend

* **Java**
* **Spring Boot**
* **Maven** para la gestión de dependencias y compilación del proyecto.

### Frontend

* **React**
* **npm** para la gestión de dependencias.

### Despliegue

* **Docker** para crear y ejecutar los contenedores de la aplicación.

## 🚀 Instalación y ejecución

### Frontend

Accede al directorio del frontend e instala las dependencias:

```bash
npm install
```

Después, inicia el servidor de desarrollo:

```bash
npm run dev
```

### Backend

Accede al directorio del backend y ejecuta la aplicación Spring Boot con Maven:

```bash
mvn spring-boot:run
```

## 💻 Desarrollo

La aplicación está dividida en un **backend desarrollado con Spring Boot** y un **frontend desarrollado con React**.

Maven se utiliza para compilar y gestionar las dependencias del backend, mientras que npm se utiliza para gestionar y ejecutar el frontend.

Docker permite crear y ejecutar los contenedores necesarios para desplegar la aplicación.

## 📌 Objetivo

El objetivo de BarberBookingWebApp es proporcionar una aplicación web sencilla para **gestionar las citas y reservas de peluquerías y barberías**.
